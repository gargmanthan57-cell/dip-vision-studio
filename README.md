🔬 DIP Techniques Demonstrated

1. Grayscale Conversion

Converts a color image into a grayscale image using weighted RGB intensity values.

2. Thresholding

Separates image regions based on a selected intensity threshold.

3. Sobel Edge Detection

Detects important edges and intensity changes in an image using horizontal and vertical gradient operations.

4. Gaussian Blur

Reduces image noise and smooths image details.

5. Sharpening

Enhances edges and fine details in an image.

6. Histogram Analysis

Displays the distribution of pixel intensity values in the processed image.

7. Document Scan

Enhances document images using grayscale conversion, local contrast enhancement, and sharpening to improve readability.

8. Lane Analysis

Demonstrates edge-based lane-region analysis using image processing techniques.

📌 Project Description

DIP Vision Studio is an interactive browser-based Digital Image Processing project. Users can upload an image and apply different processing and enhancement operations directly in the browser.

The project demonstrates practical applications of Digital Image Processing such as image enhancement, grayscale conversion, thresholding, edge detection, histogram analysis, document enhancement, and lane analysis.

The image processing is performed on the client side using JavaScript and the Canvas API.

⚠️ Limitations

This project is primarily an academic demonstration of Digital Image Processing techniques. The lane-analysis feature is intended for educational demonstration and should not be considered production autonomous-driving software.
